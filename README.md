# Godot Games

Godot 4 games:

- [Neon Drift: Asteroid Run](Neon-Drift-Asteroid-Run/) — an Asteroids-style arcade game.
- [Flappy 3D](Flappy-3D/) — a 3D Flappy Bird-style game.
- [Aim Botz Arena](Aim-Botz-Arena/) — an FPS wave mission and aim training game.
- [Red Light, Blue Light](Red-Light-Blue-Light/) — a multiplayer 3D race with server-authoritative rounds.
- [Baggage Panic](Baggage-Panic/) — a 3D endless runner where you are a suitcase on an infinite airport conveyor.
- [Trust Me, Bro!](Trust-Me-Bro/) — a Blender-authored 3D quiz show with shared-screen couch play, host/join multiplayer, eight contestants and five chaotic arena rules.

Open any folder's `project.godot` in Godot 4 and press F5. Each game has its own README with controls and details.
