# Godot Games

Two Godot 4 games:

- [Neon Drift: Asteroid Run](Neon-Drift-Asteroid-Run/) — an Asteroids-style arcade game.
- [Flappy 3D](Flappy-3D/) — a 3D Flappy Bird-style game.

Open either folder's `project.godot` in Godot 4 and press F5. Each game has its own README with controls and details.
