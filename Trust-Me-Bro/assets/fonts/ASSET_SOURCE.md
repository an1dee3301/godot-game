# Bundled fonts

These are existing free fonts, not generated media.

| Font | Source | License / required notice |
| --- | --- | --- |
| Fredoka (variable weight and width) | [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/fredoka), [font project](https://github.com/hafontia/Fredoka-One) | SIL Open Font License 1.1; retain `OFL-Fredoka.txt` |
| DM Sans | [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/dmsans), [font project](https://github.com/googlefonts/dm-fonts) | SIL Open Font License 1.1; retain `OFL-DMSans.txt` |

The original font files and copyright notices are bundled unchanged. Export presets explicitly include both license texts.
