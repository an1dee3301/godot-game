# Trust Me, Bro! production requirements

User asset policy for this game:

- Create assets through Blender modeling, rigging, animation and materials, or use existing free assets downloaded online with licenses permitting their use in the game.
- Do not generate images or videos with AI models. Do not use image/video generation workflows as concept-art prerequisites.
- Follow the two approved asset sources above rather than paid or generative asset services.
- Conventional renders of authored Blender scenes and screenshots for visual testing are allowed.
- Record asset source URLs, licenses and required credits when importing third-party assets.

Production tools and their verified installation state are documented in `Trust-Me-Bro/docs/tooling.md`. New project skills are under `.agents/skills`; load only the skills relevant to the current task. Existing GodotPrompter skills and the original Godot MCP remain available.
