# Neon Drift: Asteroid Run

A complete Asteroids-style arcade game made for Godot 4. It uses procedural vector art and generated sound, so the project has no external asset dependencies.

## Play

1. Open this folder in Godot 4.
2. Press **F5** or the play button.
3. Press **Enter** or **Space** on the title screen.

## Controls

| Action | Keys |
| --- | --- |
| Rotate | `A` / `D` or left / right arrows |
| Thrust | `W` or up arrow |
| Fire | `Space` |
| Pause | `P` or `Escape` |
| Restart | `R`, `Enter`, or `Space` after game over |

## Features

- Screen-wrapping arcade flight
- Large asteroids that split into medium and small fragments
- Increasing wave difficulty
- Scoring, chain multipliers, lives, and extra ships
- Safe respawning with a temporary shield
- Procedural starfield, vector art, particles, screen shake, and audio
- Saved best score
